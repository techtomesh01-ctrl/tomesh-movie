🧭 आसान हिंदी Fix Guide

Error दिखने पर पहले यह क्रम अपनाएँ। बिना कारण जाने payment, login, movie या storage settings न बदलें।
🔴 Website पर 500 Server Error
नीचे Recent Errors में सबसे नया 500 खोलें → “Show technical traceback” दबाएँ → error की आखिरी lines देखें। उसी exact error को ठीक करना चाहिए; अनुमान से code या database न बदलें।
🗄️ Database में FAIL
Render → CINEMA WORLD → Environment में DATABASE_URL मौजूद है या नहीं देखें। उसकी पूरी value किसी के साथ share न करें। फिर Render Logs में database connection का exact error देखें।
☁️ Cloudflare R2 में FAIL
R2_ACCOUNT_ID, R2_ACCESS_KEY_ID, R2_SECRET_ACCESS_KEY, R2_BUCKET और R2_ENDPOINT की मौजूदगी जाँचें। Secret values को screenshot/chat में न भेजें; bucket का नाम tomesh-movies ही रहने दें जब तक जानबूझकर बदलाव न किया जाए।
🚀 Code बदलने के बाद भी समस्या
GitHub commit और Render deployment का status जाँचें। Deployment “Live” होने के बाद Ctrl+F5 करें। Error Center की memory Render restart/deploy पर reset हो सकती है और यह page खुद code deploy नहीं करता।
