500 / 502 / वीडियो समस्या: सही diagnosis

हर समस्या एक ही क्लिक से अपने-आप ठीक नहीं हो सकती। यह पेज अभी सुरक्षित health checks और समाधान बताता है; बाहरी provider, Render outage, गलत credentials या Cashfree KYC को खुद नहीं बदलता।

01 · HTTP 500

Flask exception के लिए Error History और Render Runtime Logs में उसी समय की traceback देखें।

02 · HTTP 502

Render Events, deploy/build logs, worker crash, memory और Gunicorn port binding जाँचें। Proxy-level 502 Flask तक पहुँचे बिना भी हो सकता है।

03 · Video / Upload

R2 object access, सही Content-Type, HTTP Range response और browser console से वास्तविक playback जाँचें। केवल R2 connection पास होना काफी नहीं।

अपेक्षित Gunicorn start command: gunicorn app:app --bind 0.0.0.0:$PORT. यह Repair Center movies, users, payment records या storage files को delete नहीं करता।
