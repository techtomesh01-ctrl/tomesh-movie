500 / 502 के बारे में

500 आम तौर पर Flask के अंदर की exception है; उसका विवरण ऊपर Error History में दिखेगा। 502 कभी-कभी Flask तक request पहुँचने से पहले Render proxy, crashed worker या Gunicorn startup/port समस्या से आता है। यदि पूरा site 502 दे रहा है, यह पेज भी उपलब्ध नहीं होगा—Render Events, Deploy Logs और Runtime Logs देखना जरूरी है। Start command की पुष्टि करें: gunicorn app:app --bind 0.0.0.0:$PORT.

यह केंद्र diagnosis और सुरक्षित next steps देता है; यह अपने-आप external Render outages, गलत secrets, Cashfree KYC या provider-side failures नहीं बदल सकता।
