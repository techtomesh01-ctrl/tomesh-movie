# CINEMA WORLD Android App

This folder contains the first Android app version for CINEMA WORLD.

- App name: CINEMA WORLD
- Package: com.cinemaworld.app
- Version: 1.0
- Website: https://tomesh-movie.onrender.com/

The app is a lightweight Android WebView wrapper around the existing website. The website backend, database, Cloudflare R2 storage, Cashfree configuration, OTP/login, movie data, and pricing are not changed by this app project.

Build with Android Studio:
1. Open the `android-app` folder.
2. Let Gradle sync.
3. Run the app on an Android phone/emulator.
4. Build > Build Bundle(s) / APK(s) > Build APK(s).

For a public Play Store release, a production application ID, signing key, privacy policy, store assets, and payment-flow testing should be completed before publishing.
